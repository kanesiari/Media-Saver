# Media-Saver Instagram Extraction Lab (격리 실험실)

## 1. 목적 및 검증 범위
본 실험실은 오프라인 JSON 파서(`experiments/instagram-json-lab/`)에서 추출된 미디어 URL 후보와 실제 운영 다운로드 엔진(`src/utils/mediaDownloader.ts`의 `streamMediaDownload()`) 간의 **입력/출력 계약(Contract) 및 연결 가능성**을 검증하는 독립적인 테스트 환경입니다.

## 2. 한계 및 제약 사항
1. **합성(Mock) 데이터 기반 검증**:
   * 본 프로젝트에는 실제 사용자의 개인정보나 인스타그램 세션 쿠키가 포함된 라이브 응답이 저장되어 있지 않습니다.
   * 모든 테스트는 검증 가능한 합성 fixture를 기반으로 수행되며, **실제 인스타그램 라이브 환경에서의 자동 URL 추출 성공을 의미하지 않습니다.**
2. **비공식 엔드포인트의 불안정성**:
   * `__a=1` 및 `__d=dis` 등 내부 JSON 방식은 비공식 인터페이스이며, 서버/클라우드 IP 환경에서는 인스타그램 방화벽에 의해 즉시 차단(HTML 로그인 페이지 반환)됩니다.
3. **운영 코드 격리 보존**:
   * 본 디렉터리 내의 코드는 순수 실험 목적이며, `src/`, `worker.ts`, `server.ts` 등 운영 코드에 직접 연결되거나 빌드/배포에 포함되지 않습니다.
